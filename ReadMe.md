# This is a webserver created for the 42 Common core of 42 Luxemburg

## about
*this project was created by: gpochen sholz bstork*
the goal of this project was to create a webserver that is written in c++98 that is compatible with HTTP.

## setup
copy this repository to the place you need it.
```Bash
git clone https://github.com/Basti-Wood/WebServer.git
```
compile it using

	make

run it with

	./webserver [config_file]

or run it with:

	./webserver -v [config_file]

for a verbose output.
